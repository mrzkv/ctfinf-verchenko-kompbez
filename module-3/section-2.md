## №1. Задача «Забывчивый сотрудник» (заключительный этап 2025–2026 года, 8–10 классы, вариант 1)

### Условие

> Сотрудник забыл шестизначный пароль из цифр и строчных латинских букв. Переборщик проверяет пароли в порядке от `000000` до `zzzzzz`, используя алфавит `0123456789abcdefghijklmnopqrstuvwxyz`. Проверка одного пароля занимает `0,02` мс. Перебор запустили в 10:00, а к 18:00 пароль нужно успеть найти. Известно, что запуск с `000000` не завершится вовремя. С какого пароля начать перебор, чтобы гарантированно успеть?

### Решение

В алфавите 36 символов, поэтому число всех паролей равно `36 ** 6 = 2 176 782 336`.

За 8 часов можно выполнить:

```text
8 * 3 600 000 = 28 800 000 миллисекунд
28 800 000 / 0,02 = 1 440 000 000 проверок
```

Чтобы за это время дойти до последнего пароля, нужно начать с позиции:

```text
2 176 782 336 - 1 440 000 000 = 736 782 336
```

Теперь переведём этот индекс в запись по основанию 36, где цифры соответствуют символам заданного алфавита:

```python
alphabet = "0123456789abcdefghijklmnopqrstuvwxyz"

def to_password(index, length):
    result = []
    for _ in range(length):
        result.append(alphabet[index % len(alphabet)])
        index //= len(alphabet)
    return "".join(reversed(result))

start_index = 36 ** 6 - 1_440_000_000
print(to_password(start_index, 6))
```

Получаем `c6nsw0`. Индекс нулевой: ему соответствует первый пароль в последовательности `000000`.

> [!Ответ]
> `c6nsw0` (индекс `736 782 336`)

## №2. Задача «Одноразовый код» (заключительный этап 2025–2026 года, 11 класс, вариант 2)

### Условие

> Одноразовый код состоит из 6 символов. Каждый символ выбирается из 10 цифр, 20 строчных букв `a–t` или 4 специальных символов `!`, `@`, `#`, `$`. В коде должны быть хотя бы одна цифра, хотя бы одна буква и ровно два специальных символа. Два специальных символа не могут стоять рядом. Сколько разных кодов может создать система?

### Решение

Сначала выберем позиции для специальных символов. Из `C(6, 2) = 15` пар позиций исключим 5 соседних пар. Останется 10 способов.

Каждый специальный символ независимо выбирается из четырёх вариантов, значит для двух позиций есть `4 ** 2 = 16` вариантов.

Оставшиеся четыре позиции заполняются цифрами или буквами. Всего способов `30 ** 4`. Вычтем строки, состоящие только из букв (`20 ** 4`) или только из цифр (`10 ** 4`):

```text
30 ** 4 - 20 ** 4 - 10 ** 4 = 640 000
```

Перемножим три независимых выбора:

```text
10 * 16 * 640 000 = 102 400 000
```

> [!Ответ]
> `102 400 000`

## №3. Задача «Забывчивый криптограф» (отборочный этап 2025–2026 года, 8–10 классы, вариант 1)

### Условие

> Для пароля из русских заглавных букв считается хеш. Начальное значение `H0 = 11`, модуль `n = 256`. Для каждой буквы с номером `Mi` в алфавите (алфавит включает `Ё`, нумерация начинается с 1) выполняется шаг:
>
> ```text
> Hi = (Hi-1 * 7 + Mi * 13 + 2 ** i) mod 256
> ```
>
> Известно, что итоговый хеш равен `55`. Найдите подходящий пароль среди вариантов: `ПОЛИМОРФИЗМ`, `СИСТЕМА`, `ИДЕНТИФИКАЦИЯ`, `ХЕШИРОВАНИЕ`.

### Решение

Для каждого кандидата последовательно применим формулу. Буквы нужно сопоставлять позициям в заданном алфавите, где `Ё` — отдельная буква:

```python
alphabet = "АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ"
passwords = ["ПОЛИМОРФИЗМ", "СИСТЕМА", "ИДЕНТИФИКАЦИЯ", "ХЕШИРОВАНИЕ"]

def password_hash(password):
    value = 11
    for i, char in enumerate(password, start=1):
        letter_number = alphabet.index(char) + 1
        value = (value * 7 + letter_number * 13 + 2 ** i) % 256
    return value

for password in passwords:
    print(password, password_hash(password))
```

Значение `55` получается для `ИДЕНТИФИКАЦИЯ`.

> [!Ответ]
> `ИДЕНТИФИКАЦИЯ`

Источник: [отборочный этап 2025–2026 года, материалы 8–10 классов](../materials/pure-variants/2025-2026/otbor-10-class-materials/otbor-10-class.pdf).
