> Курс предназначен для подготовки к **олимапиаде имени Верченко по КОМПЬЮТЕРНОЙ БЕЗОПАСНОСТИ**,
> если вы хотите взять диплом на олимпиаде имени Верченко по криптографии вам этот курс не подойдёт.

---

Курс состоит из 6 модулей, каждый из которых посвящён отдельной теме и включает самостоятельную задачу.
Поскольку некоторые модули связаны между собой, рекомендуется проходить курс последовательно.

---

## Модуль 1. Введение в стеганографию

В этом модуле вы познакомитесь с основами стеганографии и научитесь решать типовые задачи.

### Разделы модуля

1. Что такое стеганография и её связь с криптографией.
2. Формат стеганографических задач на олимпиаде имени Верченко.
3. Практика решения задач прошлых лет.
4. Решение авторских задач.

## Модуль 2. Анализ программного кода

В этом модуле вы научитесь читать программы, восстанавливать алгоритмы по исходному коду и применять их для решения задач компьютерной безопасности.

### Разделы модуля

1. Задачи на анализ программного кода.
2. Формат задач на анализ программного кода.
3. Практика решения задач прошлых лет.
4. Решение авторских задач.

## Модуль 3. Математические методы в компьютерной безопасности

В этом модуле вы научитесь описывать задачи безопасности математическими моделями: считать пространство паролей, оценивать число вариантов и анализировать простые сценарии атак.

### Разделы модуля

1. Пространство поиска, перебор и комбинаторный подсчёт.
2. Формат задач на математические методы в компьютерной безопасности.
3. Практика решения задач прошлых лет.
4. Решение авторских задач.
