## №1. Отборочный этап. 11 класс. 2023-2024 год. Задача №5 Вариант 1 (Уровень: **Легко**)

### Условие
> Имеется исходный код функции `hashCRC(str, salt, N)`, которая осуществляет подсчет хеш-значения строки (`str`) по модулю числа `N` (хеш-значение может принимать значения от 0 до `N-1` включительно). Для усложнения подбора исходной строки функция предусматривает использование дополнительной имитовставки (`salt`), которая также используется для вычисления хеш-значения.
> 
> ```python
> def hashCRC(str: str, salt: str = "", N: int = 256):
>     res = 0 
>     for c in str:
>         res = res + ord(c)
>     for c in salt:
>         res = res + ord(c)
>     res = res % N
>     return res
> ```
> 
> Известно, что значение `salt` статическое (одинаковое для всех строк), а модуль хеш-функции равен `256` (`N`). Также известно, что для строки `"password"` хеш-значение с учетом имитовставки (`salt`) равно `249`.
> Определите, чему будет равно хеш-значение для строки `"security"` с учетом неизвестной имитовставки.
> В ответе укажите ЧИСЛО.

> [!Подсказка]
> Модульная арифметика позволяет найти сумму кодов символов соли: `(sum("password") + sum_salt) % 256 = 249`. Вычислите неизвестную `sum_salt % 256` и примените к `"security"`.

> [!Решение]
> 
> ```python
> def calc_ord_sum(s):
>     return sum(ord(c) for c in s)
> 
> # Сумма кодов для password
> sum_pass = calc_ord_sum("password")
> # (sum_pass + salt_sum) % 256 = 249
> # salt_sum % 256 = (249 - sum_pass) % 256
> salt_sum_mod = (249 - sum_pass) % 256
> 
> # Теперь для security
> sum_sec = calc_ord_sum("security")
> target_hash = (sum_sec + salt_sum_mod) % 256
> print(target_hash)
> ```

> [!Ответ]  
> 254

## №2. Заключительный этап. 11 класс. 2023-2024 год. Задача №3 Вариант 2 (Уровень: **Сложно**)

### Условие
> Система аутентификации проверяет корректность введенного пароля, сравнивая вычисленное хеш-значение. Инженеру Павлу удалось перехватить несколько запросов(паролей) и вычисленных хеш-значений (см. таблицу).
> 
> | Пароль | Хеш-значение (в 16-ом формате) |
> |---|---|
> | `batman` | `61 3C 12 D4` |
> | `greenlight` | `6E 3F 0D E7` |
> | `wonderer` | `65 3B 0E 0A` |
> | `terminator` | `69 44 17 00` |
> 
> Павлу удалось частично восстановить программный код генератора хеш-значений.
> 
> ```python
> # Функция нормирования длины пароля
> def normalizeDataLen(data: str, size: int):
>     res = ""
>     dataLen = len(data)
>     # копируем символы из data до требуемого размера size 
>     # если длина строки data меньше size, 
>     # то циклически повторяем ее требуемое количество раз
>     for i in range(0, size):
>         res = res + data[i % dataLen]
>     return res
> 
> # Функция вычисления одного хеш-значения
> def hashMask(data: str, mask: list, size: int, mod = 256):
>     sum = 0
>     for i in range(0, size):
>         sum += ord(data[i]) * mask[i]
>     sum = sum % mod
>     return sum
> ```
> 
> Павлу удалось определить, что все пароли перед вычислением хеш-значений нормируются по длине к **9 символам**. Также стало известно, что для каждого байта хеш-значения используется свой массив коэффициентов из 0 и 1 (маска). То есть для вычисления первого байта хеш-значения применяется маска1, для второго байта – маска2 и так далее.
> 
> Помогите Павлу: определите значение масок и правильное хеш-значение для пароля: `robocop`.

> [!Подсказка]
> Нормируйте известные строки до 9 символов. Для каждого из 4-х байтов хеша переберите все возможные бинарные маски длины 9 (от `000000000` до `111111111`, то есть 512 вариантов). Оставьте только ту маску, которая дает совпадение со всеми 4-мя известными паролями. 

> [!Решение]
> 
> ```python
> from itertools import product
> 
> def normalizeDataLen(data, size=9):
>     res = ""
>     for i in range(size):
>         res += data[i % len(data)]
>     return res
> 
> def hashMask(data, mask, mod=256):
>     return sum(ord(data[i]) * mask[i] for i in range(len(data))) % mod
> 
> passwords = ["batman", "greenlight", "wonderer", "terminator"]
> hashes = [
>     [0x61, 0x3C, 0x12, 0xD4],
>     [0x6E, 0x3F, 0x0D, 0xE7],
>     [0x65, 0x3B, 0x0E, 0x0A],
>     [0x69, 0x44, 0x17, 0x00]
> ]
> 
> norm_passwords = [normalizeDataLen(p) for p in passwords]
> masks = []
> 
> # Перебираем все 512 вариантов маски для каждого байта
> for byte_idx in range(4):
>     for m in product([0, 1], repeat=9):
>         # Проверяем, подходит ли маска для всех 4 примеров
>         valid = True
>         for p_idx in range(4):
>             if hashMask(norm_passwords[p_idx], m) != hashes[p_idx][byte_idx]:
>                 valid = False
>                 break
>         if valid:
>             masks.append(list(m))
>             break
> 
> # Вычисляем хеш для robocop
> target = "robocop"
> norm_target = normalizeDataLen(target)
> target_hash = [hashMask(norm_target, m) for m in masks]
> 
> print("Хеш:", " ".join(f"{b:02X}" for b in target_hash))
> print("Маски:")
> for m in masks:
>     print(m)
> ```

> [!Ответ]  
> robocopro - 63 41 13 03

## №3. Тестовый вариант. 2025-2026 год. (Уровень: **Средне**)

### Условие
> Девушке необходимо подобрать числа. На основании этих чисел программа формирует парольную фразу.
> 
> Листинг на языке Python:
> ```python
> def get_password():
>     s = "cieoserrhlutncj "
>     key = int(input("Enter key number: "))
>     step = int(input("Enter step: "))
>     size = len(s)
>     i = 0
>     while i < key * step:
>         print(s[i % size], end="")
>         i = i + step
>         step = step + 1
> ```
> 
> Спустя какое-то время Юлии потребовалось восстановить парольную фразу. Однако она забыла, какие числа использовала в качестве параметров программы.
> 
> Помогите Юлии восстановить парольную фразу, если известно, что она состоит из слов английского языка. В ответе укажите саму парольную фразу.

> [!Подсказка]
> Возможные параметры `key` и `step` скорее всего не превышают длину исходной строки (16). Напишите переборный скрипт (брутфорс), который выведет результат для всевозможных комбинаций параметров от 1 до 16 и найдите осмысленную строку визуально.

> [!Решение]
> 
> ```python
> s = "cieoserrhlutncj "
> size = len(s)
> 
> for key in range(1, size):
>     for step2 in range(1, size):
>         step = step2
>         i = 0
>         result = ""
>         while i < key * step:
>             result += s[i % size]
>             i = i + step
>             step = step + 1
>         
>         print(f"key: {key:2d}, step: {step2:2d} - {result}")
> ```
> При запуске скрипта мы увидим множество бессмысленных строк. Но строка для `key=8` и `step=3` даст `cornelius three`. Параметры 8 и 3 символизируют дату "08 марта". Это осмысленная английская фраза из двух слов.

> [!Ответ]  
> cornelius three
