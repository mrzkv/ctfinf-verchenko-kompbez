## №1. Задача "Хэширование" (Заключительный этап 2026 года, 11 класс)

### Условие

> Сотрудник компании «DC-Крипто» забыл пароль от доступа к ресурсам компании. В базе данных удалось получить хеш-значение строки его пароля:  
> `06a9a488671b09fad7b86e4458454f4e`
>
> Из внутренней документации известно, что для получения хеш-значения в компании используется собственный упрощённый алгоритм хеширования, использующий для подмешивания «соль» – константная символьная строка, добавляемая к хешируемой строке по некоторому правилу.  
> 
> Сформируйте значение хеш-строки для нового пароля пользователя – `newpassword`, при условии, что значение «соли» для всех хеш-строк одинаковое. В ответе укажите значение хеш-строки и значение «соли».

### Исходный код из условия

```python
# Нормализует соль до ровно 4 символов
def normalize_salt(salt: str) -> str:
    if len(salt) == 0:
        return ''
    if len(salt) < 4:
        return ''.join(salt[i % len(salt)] for i in range(4))
    else:
        return salt[:4]

# Добавляет соль в пароль
def weave_salt(password: str, salt: str) -> str:
    salt = normalize_salt(salt)
    half = len(password) // 2
    return salt[0:2] + password[:half] + salt[1:3] + password[half:] + salt[2:4]

# Вычисляет хеш строки
def custom_hash(s: str) -> str:
    h = [0xFE, 0xCA, 0xBE, 0xBA, 0xAD, 0xDE, 0xEF, 0xBE]
    for c in s:
        h = [ (h[i] * 65537 * (i+1) + ord(c)) % (2**16) for i in range(len(h))]
    
    hash_str = ''.join(f"{x:04x}" for x in h)
    hash_4 = s[:2] + s[-2:]
    salt = ''.join(f"{ord(ch):02x}" for ch in hash_4)
    return hash_str[:-8] + salt
```

### Решение

Внимательно изучив функцию `custom_hash()`, мы можем заметить, что она возвращает строку:
`return hash_str[:-8] + salt`

Где переменная `salt` генерируется из локальной переменной `hash_4` в виде шестнадцатеричных значений кодов ASCII (т.е. обычный перевод символов в hex). Это означает, что **последние 8 символов любого хеш-значения — это в открытом виде «соль»**, которая использовалась при хешировании (длина соли 4 символа * 2 hex символа = 8 символов).

Извлечем последние 8 символов из данного нам хеша `06a9a488671b09fad7b86e4458454f4e`:
`58454f4e`

Разобьем строку на пары и переведем из шестнадцатеричной системы (hex) в текст по ASCII-таблице:
- `58` (hex) = `88` (dec) = `X`
- `45` (hex) = `69` (dec) = `E`
- `4f` (hex) = `79` (dec) = `O`
- `4e` (hex) = `78` (dec) = `N`

Таким образом, оригинальная «соль» — **XEON**.

Далее, по условию задачи, нам нужно получить хеш для нового пароля `newpassword` с той же солью `XEON`. Для этого достаточно пропустить новые данные через исходные функции: подставить их в `weave_salt('newpassword', 'XEON')`, а затем передать результат в `custom_hash()`.

**Ответ:**
- Хеш: `07895f1c41a95f4aaee4d93858454f4e`
- Соль: `XEON`

---

### Полное решение на Python

```python
# Исходные функции из условия (normalize_salt, weave_salt, custom_hash) 
# нужно скопировать в этот скрипт...

# 1. Извлечение соли
given_hash = "06a9a488671b09fad7b86e4458454f4e"
salt_hex = given_hash[-8:]
salt = bytes.fromhex(salt_hex).decode('ascii')
print(f"Соль: {salt}")

# 2. Вычисление нового хеша
weaved = weave_salt('newpassword', salt)
new_hash = custom_hash(weaved)
print(f"Новый хеш: {new_hash}")
```

## №2. Задача "Исходный код" (Отборочный этап 2026 года, 11 класс)

### Условие

> В связи с усилением требований к защите данных, компания «КриптоТех» разработала новый алгоритм шифрования для защиты конфиденциальных сообщений. Алгоритм использует циклический сдвиг и модульную арифметику для обеспечения безопасности.
>
> Разработчики по ошибке опубликовали код функции шифрования в публичном репозитории. Зная исходный код и перехваченные зашифрованные данные, определите исходное текстовое сообщение. Регистр символов в ответе имеет значение!
> 
> Зашифрованное сообщение: `28 68 70 76 80 80 104`

### Исходный код из условия

```python
def encrypt(text, key):
    encrypted = []
    for i, char in enumerate(text):
        shifted = (ord(char) + key + 7*i) % 128
        encrypted.append(shifted)
    return encrypted
```

### Решение

Изучив код, мы видим, что каждый символ шифруется по математической формуле: `shifted = (ord(char) + key + 7*i) % 128`, где `i` — индекс символа, `char` — сам символ, а `key` — неизвестный нам числовой ключ.

Для расшифровки необходимо применить обратную операцию (дешифрование). Так как используется взятие остатка от деления на 128 (`% 128`), то значение исходного кода символа можно выразить как:
`char_code = (shifted - key - 7*i) % 128`

Мы не знаем секретный ключ `key`, но поскольку символы ограничены таблицей ASCII (0-127) и операция идет по модулю 128, ключей всего 128 (от 0 до 127). Мы можем легко написать скрипт, который переберет все возможные ключи (*брутфорс*) и выведет все 128 вариантов расшифрованной строки. 

Ответом должно быть осмысленное слово, и так как регистр имеет значение, мы быстро визуально сможем определить правильный ключ. Программно перебрав все ключи от 0 до 127, мы обнаружим, что при `key = 72` получается осмысленное английское слово `Tupolev`.

**Ответ:** `Tupolev` (ключ: 72)

---

### Полное решение на Python

```python
encrypted_data = [28, 68, 70, 76, 80, 80, 104]

# Перебираем все возможные ключи от 0 до 127
for key in range(128):
    decrypted_chars = []
    for i, shifted in enumerate(encrypted_data):
        # Обратное преобразование по модулю 128
        char_code = (shifted - key - 7 * i) % 128
        decrypted_chars.append(chr(char_code))
    
    # Собираем символы в строку
    word = "".join(decrypted_chars)
    
    # Выводим только те слова, которые состоят исключительно из букв
    # (отсекаем мусор, чтобы было проще искать глазами)
    if word.isalpha():
        print(f"Ключ: {key}, Сообщение: {word}")
```

## Основные идеи задач

Обобщим основные идеи, которые часто встречаются в задачах на анализ программного кода (Reverse / Crypto-Reverse) олимпиады имени Верченко:

1. **Анализ возвращаемых значений.** Иногда, как в первой задаче, часть "секретных" данных (например, соль или часть ключа) может в открытом или слабо закодированном виде "приклеиваться" к результату функции. Внимательное чтение оператора `return` может сэкономить часы реверс-инжиниринга.
2. **Перебор (Брутфорс).** При отсутствии сложных криптографических примитивов, небольшое пространство ключей (например, `key` в диапазоне от 0 до 128) можно и нужно перебирать программно. Написание собственных скриптов дешифровки (декрипторов) — базовый навык для таких задач.
3. **Модульная арифметика.** Операция взятия остатка от деления (`%`) очень часто используется в задачах шифрования. Понимание того, как от неё избавиться или найти обратное значение: `(a - b) % n`, необходимо для решения криптографических задач.
4. **Кодировка ASCII.** Практически всегда текстовая информация кодируется в числовом виде с помощью таблицы ASCII (функции `ord()` и `chr()` в Python).
