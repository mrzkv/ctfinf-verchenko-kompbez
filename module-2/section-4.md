## №1. Авторская задача. Борда сборной Москвы. (Уровень: **Легко**)

### Условие
> Анализируя исходный код борды сборной мск, вы обнаружили функцию, которая хеширует пароль администратора. 
> В исходном коде скрипта захардкожено эталонное хеш-значение: `9-6-14-126-21-230-230-329`
>
> Исходный код функции хеширования:
> ```python
> def custom_hash(word):
>     hashed = []
>     for char in word.lower():
>         if 'a' <= char <= 'z':
>             char_index = ord(char) - ord('a') + 1
>             val = char_index ** 2 + 5
>             hashed.append(str(val))
>     return "-".join(hashed)
> ```
> Определите исходное слово (пароль). В ответе укажите его английскими буквами в нижнем регистре.

> [!Подсказка]
> Разбейте строку по символу `"-"`. Рассмотрите математическую формулу по которой создаётся хэш-значения, возможно она обратима.

> [!Решение]
> Каждый символ пароля зашифрован независимо, а результаты склеены через дефис `"-"`. Для расшифровки нам достаточно получить список всех значений, разбив строку встроенной функцией `.split("-")`. 
> 
> Так как пароль состоит только из английских букв (всего 26 вариантов), самым быстрым и надежным способом будет написать небольшой скрипт-декриптор. Он вычислит хеши для всех возможных букв от `a` до `z`, сохранит их в словарь, а затем сопоставит числа из нашей строки с буквами.
>
> ```python
> # 1. Создаем словарь соответствий хеш -> буква
> hash_to_char = {}
> for i in range(26):
>     char = chr(ord('a') + i)
>     char_index = i + 1
>     val = str(char_index ** 2 + 5)
>     hash_to_char[val] = char
> 
> # 2. Расшифровываем строку
> target_hash = "9-6-14-126-21-230-230-329"
> parts = target_hash.split("-")
> 
> result = ""
> for p in parts:
>     result += hash_to_char[p]
> 
> print(result)
> ```

> [!Ответ]  
> backdoor

## №2. Авторская задача. Потерянный ключ (Уровень: **Легко**)

### Условие
> Сборная Татарстана взломала нашу борду и посылает данные в Казань, мы остановили атаку, но нужно узнать что мы уже потеряли, вот их функция шифрования
> ```python
> def encrypt(message, key):
>     return [ord(char) ^ key for char in message]
> ```
>
> Значение ключа неизвестно. Сохранённый шифртекст:
>
> ```text
> 4!=!19!=!1!=!74!=!9!=!8!=!19!=!74!=!14!=!9!=!1
> ```
>
> Известно, что исходное сообщение состоит из строчных английских букв и дефисов. Определите ключ и исходное сообщение. В ответе укажите сообщение.

> [!Подсказка]
> Разбейте шифртекст по разделителю `"!=!"` и подберите XOR ключ

> [!Решение]
> Операция XOR обратима: если `cipher = ord(char) ^ key`, то `char = cipher ^ key`. Переберём возможные значения ключа и проверим, что все получившиеся символы входят в допустимый алфавит:
>
> ```python
> ciphertext = "4!=!19!=!1!=!74!=!9!=!8!=!19!=!74!=!14!=!9!=!1"
> values = [int(value) for value in ciphertext.split("!=!")]
> alphabet = set("abcdefghijklmnopqrstuvwxyz-")
>
> for key in range(256):
>     message = "".join(chr(value ^ key) for value in values)
>     if all(char in alphabet for char in message):
>         print("Ключ:", key)
>         print("Сообщение:", message)
> ```
>
> Подходящий ключ — `103` (то есть `0x67`). После XOR с ним числа шифртекста превращаются в символы исходного сообщения.

> [!Ответ]  
> ctf-not-inf

## №3. Авторская задача. Фрагменты резервной копии. (Уровень: **Легко**)

### Условие
> После атаки сборной Татарстана часть резервной копии платформы сборной Москвы оказалась зашифрована. В скрипте восстановления нашли функцию:
>
> ```python
> def encrypt(message):
>     blocks = []
>     for i in range(0, len(message), 3):
>         blocks.append(message[i:i + 3][::-1])
>     return "|".join(blocks)
> ```
>
> В резервной копии сохранился шифртекст:
>
> ```text
> at2|rat|hc1|cka|kah
> ```
>
> Восстановите флаг. В ответе укажите его без изменений.

> [!Подсказка]
> Функция обрабатывает строку блоками по три символа. Операция `[::-1]` разворачивает символы внутри блока. При расшифровке повторите эту операцию для каждого блока.

> [!Решение]
> Разобьём шифртекст по разделителю `"|"`, развернём каждый блок и склеим получившиеся строки:
>
> ```python
> ciphertext = "at2|rat|hc1|cka|kah"
> blocks = ciphertext.split("|")
> flag = "".join(block[::-1] for block in blocks)
> print(flag)
> ```
>
> После разворота блоков `at2`, `rat`, `hc1`, `cka`, `kah` получаем `2ta`, `tar`, `1ch`, `akc`, `hak`.

> [!Ответ]  
> 2tatar1chakchak

## №4. Авторская задача. Перехваченный токен. (Уровень: **Средне**)

### Условие
> При восстановлении борды специалисты нашли фрагмент скрипта, которым шифровали данные для эксфильтрации:
>
> ```python
> def encrypt(message, key):
>     encrypted = []
>     for i, char in enumerate(message):
>         value = (ord(char) + key * (i + 1)) % 128
>         encrypted.append(value)
>     return encrypted
> ```
>
> Значение `key` неизвестно, но известно, что это целое число от 0 до 127. Перехваченный шифртекст:
>
> ```text
> 110, 15, 3, 95, 41, 47, 125, 75, 70, 30, 112
> ```
>
> Известно, что флаг состоит из 11 строчных английских букв и цифр. Определите ключ и восстановите флаг. В ответе укажите флаг.

> [!Подсказка]
> Переберите возможные значения `key`. Для каждого числа из шифртекста примените обратное преобразование: `(value - key * (i + 1)) % 128`. Оставьте результат, состоящий только из строчных английских букв и цифр.

> [!Решение]
> В функции к коду каждого символа прибавляется сдвиг, зависящий от позиции символа, после чего берётся остаток от деления на 128. Для расшифровки вычтем этот сдвиг по модулю 128 и переберём все возможные значения ключа:
>
> ```python
> encrypted = [110, 15, 3, 95, 41, 47, 125, 75, 70, 30, 112]
> alphabet = "abcdefghijklmnopqrstuvwxyz0123456789"
>
> for key in range(128):
>     message = "".join(
>         chr((value - key * (i + 1)) % 128)
>         for i, value in enumerate(encrypted)
>     )
>     if all(char in alphabet for char in message):
>         print("Ключ:", key)
>         print("Флаг:", message)
> ```
>
> Подходящий ключ — `11`.

> [!Ответ]  
> cyb3rm0sc0w
