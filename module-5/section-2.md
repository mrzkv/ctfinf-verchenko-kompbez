## №1. Виженер. Заключительный этап 2025–2026 года, 11 класс, задача №5, вариант 1

### Условие

> В издательстве «Книжный мир» системный администратор нашёл зашифрованное вложение в письме о подготовке рассказа к печати. Копию базы данных издательства уже опубликовали в интернете. Нужно выяснить, содержится ли в письме пароль от этой базы.
>
> Сообщение зашифровано шифром Виженера. Буквы русского алфавита с `Ё` нумеруются от 0 до 32. Ключевое слово повторяется по длине текста, а номер каждой буквы открытого текста складывается с номером соответствующей буквы ключа по модулю 33. Для расшифровки номер буквы ключа вычитают по модулю 33.
>
> Возможные ключи — `МАРШАК`, `ТЮТЧЕВ`, `ЕСЕНИН`, `ПУШКИН`, `ОГАРЁВ`. Найдите пароль от базы данных в зашифрованном сообщении.
>
> [Шифротекст в файле message_v1.txt](../materials/pure-variants/2025-2026/zakl-11-class-materials/5/message_v1.txt)
>
> [Оригинал задачи](../materials/pure-variants/2025-2026/zakl-11-class-materials/zakl-11-class.pdf#page=17)

### Решение

Проверим каждый ключ. Например, с ключом `ПУШКИН` первая буква шифротекста `Г` имеет номер 3, а буква ключа `П` — номер 16. Получаем `(3 − 16) mod 33 = 20`, что соответствует букве `У`.

```python
from pathlib import Path

path = Path("materials/pure-variants/2025-2026/zakl-11-class-materials/5/message_v1.txt")
ciphertext = path.read_text(encoding="utf-8").strip()
alphabet = "АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ"
numbers = {letter: index for index, letter in enumerate(alphabet)}
keys = ("МАРШАК", "ТЮТЧЕВ", "ЕСЕНИН", "ПУШКИН", "ОГАРЁВ")
marker = "ПАРОЛЬОТБАЗЫДАННЫХ"

for key in keys:
    plaintext = "".join(
        alphabet[(numbers[letter] - numbers[key[i % len(key)]]) % len(alphabet)]
        for i, letter in enumerate(ciphertext)
    )
    print(key, plaintext[:40])
    if marker in plaintext:
        start = plaintext.index(marker)
        print(plaintext[start:start + len(marker) + 20])
```

Только с ключом `ПУШКИН` получается осмысленный текст. Он начинается с `УЛУКОМОРЬЯДУБЗЕЛЕНЫЙ`. Внутри находим фрагмент `ПАРОЛЬОТБАЗЫДАННЫХСТИХОТВОРЕНИЕ`.

> [!Ответ]
> `СТИХОТВОРЕНИЕ`

## №2. Частотный анализ. Заключительный этап 2025–2026 года, 8–10 классы, задача №5, вариант 1

### Условие

> В компании «PostMail» отдел информационной безопасности перехватил зашифрованное письмо. Алгоритм шифрования неизвестен. Аналитики предоставили таблицу частот русских букв.
>
> Расшифруйте сообщение и укажите пароль администратора.
>
> | Буква | Частота | Буква | Частота | Буква | Частота | Буква | Частота | Буква | Частота |
> | :---: | ---: | :---: | ---: | :---: | ---: | :---: | ---: | :---: | ---: |
> | А | 6,72 % | З | 1,12 % | П | 2,52 % | Ч | 1,68 % | Я | 2,15 % |
> | Б | 1,59 % | И | 7,84 % | Р | 5,41 % | Ш | 0,65 % | | |
> | В | 4,38 % | Й | 1,31 % | С | 4,29 % | Щ | 0,65 % | | |
> | Г | 1,21 % | К | 3,82 % | Т | 7,74 % | Ъ | — | | |
> | Д | 3,92 % | Л | 3,73 % | У | 3,17 % | Ы | 1,21 % | | |
> | Е | 7,93 % | М | 2,43 % | Ф | 0,65 % | Ь | 2,52 % | | |
> | Ё | 0,75 % | Н | 5,88 % | Х | 1,21 % | Э | 0,47 % | | |
> | Ж | 1,40 % | О | 10,54 % | Ц | 0,75 % | Ю | 0,37 % | | |
>
> [Зашифрованное письмо в файле letter_v1.txt](../materials/pure-variants/2025-2026/zakl-10-class-materials/5/letter_v1.txt)
>
> [Оригинал задачи](../materials/pure-variants/2025-2026/zakl-10-class-materials/zakl-10-class.pdf#page=17)

### Решение

В письме сохранились пробелы и знаки препинания. Проверим гипотезу, что буквы заменяли простой подстановкой. Считаем только русские буквы, включая `ё`, и игнорируем регистр.

```python
from collections import Counter
from pathlib import Path

path = Path("materials/pure-variants/2025-2026/zakl-10-class-materials/5/letter_v1.txt")
letter = path.read_text(encoding="utf-8")
alphabet = "абвгдеёжзийклмнопрстуфхцчшщъыьэюя"
counts = Counter(char for char in letter.lower() if char in alphabet)
total = sum(counts.values())

for char, count in counts.most_common():
    print(f"{char}  {count:3}  {count / total:.2%}")
```

Чаще всего в шифротексте встречается `ж` (10,54 %). В таблице такую частоту имеет `о`. Следующие частые буквы дают `э → е`, `б → и`, `к → т` и `ш → а`. Так можно восстановить большую часть соответствий.

У `з` и `ф` одинаковая частота, а в таблице им могут соответствовать `п` и `ь`. По контексту видно, что `Зшиждф` превращается в `Пароль`, значит `з → п` и `ф → ь`. Аналогично `гшг ку б нжкэд` читается как `как ты и хотел`, а `кшвёбг` — как `тайник`. Уточнив остальные замены по соседним словам, добавим подстановку в предыдущий скрипт.

```python
substitution = {
    "а": "з", "б": "и", "в": "й", "г": "к", "д": "л", "е": "м", "ё": "н",
    "ж": "о", "з": "п", "и": "р", "й": "с", "к": "т", "л": "у", "м": "ф",
    "н": "х", "о": "ц", "п": "ч", "р": "ш", "с": "щ", "у": "ы", "ф": "ь",
    "х": "э", "ц": "ю", "ч": "я", "ш": "а", "щ": "б", "ъ": "в", "ы": "г",
    "ь": "д", "э": "е", "ю": "ё", "я": "ж",
}
uppercase = {source.upper(): target.upper() for source, target in substitution.items()}
plaintext = letter.translate(str.maketrans(substitution | uppercase))
for line in plaintext.splitlines():
    if line.startswith("Пароль:"):
        print(line)
```

> [!Ответ]
> `ЕвгенийКрутойСетевик`

## №3. Таблица символов. Заключительный этап 2024–2025 года, 11 класс, задача №2, вариант 1

### Условие

> На ноутбуке агента обнаружили таблицу из 32 строк и 32 столбцов и формулы перехода от одной клетки к следующей. В клетках по этому маршруту записан пароль.
>
> Первая буква находится в клетке с координатами `(x₀, y₀) = (5, 6)`. Нумерация начинается с нуля, `x` обозначает столбец, а `y` — строку. Следующие координаты вычисляются так
>
> ```text
> xᵢ₊₁ = ((xᵢ + a²)^(a | xᵢ) + a) mod 32
> yᵢ₊₁ = ((yᵢ + b²)^(b | yᵢ) + b) mod 32
> ```
>
> Здесь `^` обозначает возведение в степень, `|` — побитовое ИЛИ, `mod` — остаток от деления. Пароль состоит из 13 букв и является осмысленным словом. Укажите пароль и значения параметров `a` и `b`.
>
> [Дополнительный материал — таблица символов из официального решения в файле letter-table.txt](../materials/module-5/section-2/letter-table.txt)
>
> [Оригинал условия с формулами](../materials/pure-variants/2024-2025/zakl-11-class-materials/zakl-11-class.pdf#page=6)

### Решение

Как в официальном решении, переберём параметры `a` и `b` от 0 до 31. Для каждой пары начнём с клетки `table[6][5]`, где находится `К`, и сделаем 12 переходов. Функция `pow(base, exponent, 32)` вычисляет остаток от степени без вычисления самой степени.

```python
from ast import literal_eval
from pathlib import Path

path = Path("materials/module-5/section-2/letter-table.txt")
table = literal_eval(path.read_text(encoding="utf-8"))

for a in range(32):
    for b in range(32):
        x, y = 5, 6
        letters = [table[y][x]]
        for _ in range(12):
            x = (pow(x + a**2, a | x, 32) + a) % 32
            y = (pow(y + b**2, b | y, 32) + b) % 32
            letters.append(table[y][x])
        print(a, b, "".join(letters))
```

Среди 1024 строк перебора находим осмысленное слово `КЛАССИФИКАЦИЯ` при `a = 18` и `b = 13`.

> [!Ответ]
> `КЛАССИФИКАЦИЯ`, `a = 18`, `b = 13`.
